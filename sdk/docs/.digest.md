## ARCHITECTURE SUMMARY
Pattern: Ports/adapters with chain-of-responsibility orchestrator.
Stack: TypeScript, Node.js, Vitest, Docker.
Flow: optional REFINEMENT -> BOOTSTRAP -> PLANNING -> DEVELOPMENT -> REVIEW -> TRANSITION -> MEMORY -> DEPLOY -> HALTED; CASCADE_BLOCKED handles dependents. Existing BACKLOG resumes at PLANNING+. Planning persists IN_PROGRESS; Review/Cascade terminate; Transition requires terminal status and queues next feature. Refinement uses `pbb-design`; Bootstrap/Planning use traceable context.
Modes: `thinking`=LOW, `deep_thinking`=HIGH, undefined=AUTO; all use REFINEMENT. `quick` skips Review; `fast` requires `--refine`.
Completion: `quick` emits 003/004; phase retries/Review/Memory prefer REFINEMENT.md; Refinement consumes SCOPE.md; tasks need owners; TDD resumes at REVIEW; skipped Review has no synthetic scores.
Layers: domain, application, adapters, composition. QA has run/report/exploratory/auth actions and redacted evidence. MCP supports legacy and stateless requests.
QA uses routed docs, JSON handoffs, mandatory scenario IDs, plan-only repair, and runtime prerequisites. Adaptive analysis runs once. Reports derive summary, coverage, and status from runtime results; verified targets expire after 30 days.
CLI defaults to Claude when --agent is omitted.
QA reuses CLI sessions; browser contexts isolate tests and wait for selectors/URLs.
Server: One project per job; failed worktrees resume. Completion needs every feature done. Server handles branch deployment and shared secret screening.
DI: Inject ports through constructors/options; use factories at composition boundaries.
REQUIRED: Propagate AbortSignal/prompt transport, resolve phase model/effort, use atomic replacement, validate DTOs, and run RTK checks.
Startup: Refinement uses evidence to decide on up to 4 setup questions. Bootstrap runs project-memory once for roots lacking docs/.digest.md or docs/.graph.json, with the selected scope as context.
PROHIBITED: Bind orchestration decisions to concrete runners, place HTTP transport in use cases, or bypass state adapters.
