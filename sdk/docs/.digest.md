## ARCHITECTURE SUMMARY
Pattern: Ports/adapters with chain-of-responsibility orchestrator.
Stack: TypeScript, Node.js, Vitest, Docker.
Flow: REFINEMENT? -> BOOTSTRAP -> PLANNING -> DEVELOPMENT -> REVIEW -> TRANSITION -> MEMORY -> DEPLOY -> HALTED; CASCADE_BLOCKED handles dependents. REFINEMENT is new-scope only; existing BACKLOG resumes at PLANNING+; TRANSITION queues next feature. Planning persists IN_PROGRESS; Review/Cascade set terminal status; Transition requires terminal status. Refinement uses `pbb-design`; Bootstrap/Planning use traceable context.
Modes: `thinking` uses LOW with REFINEMENT; `deep_thinking` uses HIGH; undefined uses AUTO with REFINEMENT; `quick` skips Review; `fast` requires `--refine`.
Completion: `quick` emits 003/004; Bootstrap/Planning/Development retries/Review/Memory prefer REFINEMENT.md; Refinement consumes SCOPE.md; tasks need owners; existing TDD resumes at REVIEW; skipped Review has no synthetic scores.
Layers: domain, application, adapters, composition. QA has run/report/exploratory/auth actions and redacted evidence. MCP supports legacy and stateless requests.
QA uses routed docs and JSON handoffs. Invalid plans get one repair. Verified targets expire after 30 days.
CLI prompts when --agent is omitted; Claude CLI is preselected.
QA reuses runner sessions; browsers use isolated contexts and selector/URL waits; CLI executions start fresh.
Server: One project per job. Failed worktrees persist for resume. Complete jobs only after all backlog features complete. Server owns branch deployment and shares sensitive-file screening with SDK.
DI: Inject ports through constructors/options; use factories at composition boundaries.
REQUIRED: Propagate AbortSignal/prompt transport, resolve phase model/effort, use atomic replacement, validate DTOs, and run RTK checks.
PROHIBITED: Bind orchestration decisions to concrete runners, place HTTP transport in use cases, or bypass state adapters.
