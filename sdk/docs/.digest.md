## ARCHITECTURE SUMMARY
Pattern: Ports and Adapters around a Chain-of-Responsibility orchestrator.
Stack: TypeScript 7.0.2, Node.js, Vitest 4.1.10, Docker.
Flow: BOOTSTRAP -> optional REFINEMENT -> PLANNING -> DEVELOPMENT -> REVIEW -> TRANSITION -> MEMORY -> DEPLOY -> HALTED; CASCADE_BLOCKED handles dependency failures.
Layers: domain/orchestration, application, inbound adapters, outbound adapters, registration/composition.
DI: Inject ports through constructors or orchestrator options; use registries and factories at composition boundaries.
REQUIRED: Propagate AbortSignal, use atomic file replacement, validate transport DTOs, and run checks through RTK.
PROHIBITED: Bind orchestration decisions to concrete runners, place HTTP transport in use cases, or bypass state adapters.

## TEST SUMMARY
Framework: Vitest 4.1.10 with V8 coverage; E2E config `vitest.e2e.config.ts` uses 30-second test and hook timeouts.
Commands: `rtk npm run lint`, `rtk npm run build`, `rtk npm run typecheck`, `rtk npm run test`, `rtk npm run test:e2e`.
Coverage Thresholds: None configured; do not claim numeric gates.
