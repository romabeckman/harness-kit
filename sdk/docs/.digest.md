# Project Digest

## LAST UPDATED
2026-08-05

## ARCHITECTURE SUMMARY
Pattern: Ports and Adapters (Hexagonal Architecture) with static registry/factory pattern for agent runners.
Core Loop: Refinement -> Planning -> Development (TDD Loop) -> Review -> StateCheck -> Transition -> Memory -> Deploy -> HALTED.
Inbound Port: `IFileStateManager` (atomic write-then-rename filesystem operations).
Outbound Port: `IAgentRunner` (timeout AbortSignal propagation for CLI/API strategy runners).
Key Constraints: No direct DB calls in controllers; mandatory AAA pattern in tests; zero real API calls in unit tests.

## TEST SUMMARY
Framework: Vitest 1.6.0 (E2E config: `vitest.e2e.config.ts`).
Commands: `rtk npm test` (unit/integration), `rtk npm run test:e2e` (E2E scenarios), `rtk npm run typecheck`.
Coverage Thresholds: Domain 90%, Use Cases 85%, Infrastructure 80%, Global 85%.
