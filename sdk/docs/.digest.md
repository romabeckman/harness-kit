## ARCHITECTURE SUMMARY
Pattern: Ports and Adapters around a Chain-of-Responsibility orchestrator.
Stack: TypeScript 7.0.2, Node.js, Vitest 5.0.0, Docker.
Flow: BOOTSTRAP -> optional REFINEMENT -> PLANNING -> DEVELOPMENT -> REVIEW -> TRANSITION -> MEMORY -> DEPLOY -> HALTED; CASCADE_BLOCKED handles dependency failures. Independent QA runs LLM PLANNING -> plan VALIDATION -> one target probe -> driver EXECUTION -> adaptive ANALYSIS -> LLM REPORTING, streams typed progress plus final summary frame, persists immutable plans, original scopes in plan-level SCOPE.md files, run state, reports, and numbered evidence. Profiles include API, web, web-game, mobile-web, accessibility, MCP, CLI, WebSocket, security, and full. MCP accepts JSON or SSE responses, matches structured result content case-insensitively, and supports explicit state, reason, and error expectations. SDK tests use synthetic data and injected drivers without external HTTP or project-specific data.
Layers: domain/orchestration, application, inbound adapters, outbound adapters, registration/composition. QA evidence folders use a zero-padded three-digit execution prefix followed by scenario ID.
DI: Inject ports through constructors or orchestrator options; use registries and factories at composition boundaries.
REQUIRED: Propagate AbortSignal, expose prompt transport through `IAgentRunner`, resolve model/effort per phase including QA, use atomic file replacement, validate transport DTOs, and run checks through RTK.
PROHIBITED: Bind orchestration decisions to concrete runners, place HTTP transport in use cases, or bypass state adapters.

## TEST SUMMARY
Framework: Vitest 5.0.0 with V8 coverage; E2E config `vitest.e2e.config.ts` uses 30-second test and hook timeouts.
Commands: `rtk npm run lint`, `rtk npm run build`, `rtk npm run typecheck`, `rtk npm run test`, `rtk npm run test:e2e`.
Coverage Thresholds: None configured; do not claim numeric gates.
